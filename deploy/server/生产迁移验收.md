## 实施顺序与放行条件

1. 独立身份：登录、退出、过期、找回账户、限速、个人/家庭权限隔离；去除正式包内共用密钥。会话不存浏览器可读存储，敏感接口禁止缓存；未登录不请求或展示家庭健康信息。需要自动测试错误密码、跨用户/家庭访问、过期、撤销、刷新恢复和退出清理，并在手机浏览器实测。
2. 持久化：独立生产 PostgreSQL、显式迁移、独立演示库；用合成样本验证重启/重新发布不丢失、备份可恢复。不得把演示家庭和演示凭证迁入真实用户库。
3. 常驻任务：独立 worker，测试任务重试、进程重启、重复上传幂等、授权撤回后停止投递、静默时段、失败告警；不能仅凭配置开关认为 worker 正常。
4. 产品核心链路：设备受控绑定、真实凭证轮换、上传去重、质量降级、待认领/纠正、自动报告、长期趋势、行动反馈；真实硬件验收另列，机械臂不因发布自动启用。
5. 发布验收：隐私说明和明确同意、数据导出/删除、真实通知渠道、监控限额、备份恢复、手机端完整流程。先独立预发布验证，再切主域名；保留版本和回滚步骤。
