## 项目说明

PoopSense（便感智护）是一套面向家庭健康照护场景的隐私优先型智能硬件系统，重点解决老人和儿童难以持续主动记录、家庭成员难以及时了解健康变化，以及传统健康产品只展示数据、难以促成行动的问题。便便感知器采集与排便相关的环境和状态特征并传入软件端；主 Agent 联合健康医生、生活教练、家庭管家、安全仲裁、主动关怀及社交/社区 Agent，结合长期记忆和历史趋势，通过动画、解释和可执行建议反馈给用户。当系统提出补水建议后，经过用户确认与安全检查，可通过 Tooling 调用机械臂、VBot 和提醒机器人。项目已完成传感数据链路、软件 Agent 系统、机械臂固定点位取杯、提起和递水实机验证，以及 VBot 预设路线导航和提醒机器人推水动作，形成从健康感知、Agent 分析、用户确认到具身执行和结果反馈的整体产品架构。

## 第三方硬件说明

PoopSense 为团队从零开发的原创项目。项目采用 Panthera 机械臂、VBot 机器狗及相关 SDK 作为通用硬件和开发工具。团队原创完成产品定义、传感数据链路、软件 Agent 架构、长期记忆、安全仲裁、机器人 Tooling、动作轨迹标定及整体健康行动流程。
