## 项目说明

PoopSense（便感智护）是一套面向家庭健康照护场景的隐私优先型智能硬件系统，重点解决老人和儿童难以持续主动记录、家庭成员难以及时了解健康变化，以及传统健康产品只展示数据、难以促成行动的问题。感知器使用 BME688、APDS9960、MLX90640 和 AS7341 采集气体响应、接近状态、热成像形状特征与颜色信息；ESP32 统一读取后，经 USB Serial 发送至电脑端 Python Adapter，完成解析、特征提取、分类、质量评估和 Session JSON 封装。PoopSense App 展示检测结果、动画和趋势，主 Agent 联合健康医生、生活教练、家庭管家、安全仲裁、主动关怀及社交/社区 Agent，结合长期记忆生成可执行建议。当系统提出补水建议后，经过用户确认与安全检查，Tooling 可调用机械臂、VBot 和提醒机器人完成取杯、运输、递水、推水提醒及结果反馈，形成“健康感知—数据分析—AI 决策—实体执行”的完整闭环。

## 六层架构

1. 感知层：BME688、APDS9960、MLX90640、AS7341。
2. 嵌入式层：ESP32 负责传感器读取、基础预处理和检测流程管理。
3. 边缘计算层：MacBook/边缘设备上的 Python Adapter 负责分类与 JSON 封装。
4. 应用层：PoopSense App 展示 Session、动画、趋势和交互入口。
5. 智能决策层：主 Agent、专业 Agent、长期记忆和安全仲裁生成行动任务。
6. 执行层：机器人、VBot 和 Panthera 机械臂执行移动、取水、递水与提醒。

## 第三方硬件说明

PoopSense 为团队从零开发的原创项目。项目采用 Panthera 机械臂、VBot 机器狗及相关 SDK 作为通用硬件和开发工具。团队原创完成产品定义、传感数据链路、软件 Agent 架构、长期记忆、安全仲裁、机器人 Tooling、动作轨迹标定及整体健康行动流程。
