# 隐私与安全设计

## 隐私原则

1. **默认最少采集**：Agent 只获取完成当前任务需要的上下文域。
2. **先认领再进入个人趋势**：候选家庭成员不会被系统自动绑定。
3. **权限分离**：查看、编辑、通知和原始数据授权分别管理。
4. **可撤回**：家庭授权、社区内容和 Agent 连接均可撤回。
5. **事实不可覆盖**：用户纠正以新版本追加，原始设备事实保留审计链。
6. **公开 Demo 去标识化**：不使用真实姓名、家庭密钥或真实健康记录。

## 医疗表达边界

- PoopSense 提供个人趋势参考，不提供疾病诊断。
- 环境温湿度只作为设备环境信息，不解释为人体健康指标。
- 模型不能改变确定性规则输出的风险等级。
- 覆盖率或可靠样本不足时，不生成虚假的个人趋势。
- 特殊颜色等敏感信号优先要求用户确认，并提供适度的专业就医建议。

## 机器人动作安全

- 必须经过用户明确确认。
- 只调用注册且版本化的机器人 Skill。
- 检查机器人连接、运行状态和动作前置条件。
- 提供到位判断、超时、停止、失败终态和审计记录。
- 递水时先等待用户接杯确认，再允许松爪。
- 真实机器人控制接口不得直接暴露在公网。

## 密钥管理

- 模型密钥仅通过系统环境变量或本地 `.env.local` 提供。
- `.env.local`、数据库和日志均由 `.gitignore` 排除。
- 前端不包含生产长期凭证。
- 生产环境关闭 Demo bootstrap，并接入正式登录和权限系统。
