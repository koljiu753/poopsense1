# 2026-09-10 · 记录、回应与导航体验更新

这次更新围绕家庭成员的“找到记录 → 看懂建议 → 留下回应 → 回看变化”流程展开，恢复与海报一致的粉、黄、蓝品牌和角色场景，并补齐跨页操作、浏览器历史与输入面板。

## 主要变化

- 首页用成员日记、日期、角色气泡和近期足迹呈现记录；报告延续同一角色，先显示观察、一项优先建议和回应。已保存选择可在对应记录中找回；紧急和信息不足说明保持完整。
- 健康拆分为记录、行动、趋势。行动页先展示后续可靠观察和主观感受，再提供源报告与可展开依据；采用意向和实际执行保持区分，前后变化不解释为因果。
- 新记录在健康、广场和“我的”通过页面内提醒呈现，不直接打断正在进行的操作。队列优先保留安全项，显示记录时间和待看数量。
- 浏览器返回、前进、刷新及页面内返回使用统一导航。页面地址包含成员、健康分区、趋势范围及报告/行动来源；返回恢复可用的滚动位置和焦点，失效记录给出重新读取或返回入口。
- 同成员切页保留未提交的广场草稿和设置编辑，重新进入时刷新服务端状态；成员或家庭连接范围变化后隔离状态。记录与趋势独立读取，趋势失败不再挡住记录。
- 发布面板支持键盘焦点、关闭后位置恢复，并随浏览器可见区域缩小调整，正文独立滚动；每条发布仍需明确确认。

## 修复

- 旧成员、旧请求和迟到模拟检测结果不再强制打开错误记录；报告按当前成员可查看的记录校验，不用最新记录替换失效链接。
- 报告刷新后仍保留返回关系；重复点击相同页面不重复创建历史条目，同条记录的暂时缺失不重复触发自动分析。
- 保留无记录时的独立咨询入口；保存失败不会显示已保存，迟到读取不会覆盖新选择。
