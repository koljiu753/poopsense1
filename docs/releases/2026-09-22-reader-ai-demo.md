# Reader 手动采样 AI 演示解读

日期：2026-09-22。本次功能只解释卡纸、橡皮泥等演示材料的测量记录，不生成健康报告。发布与实际验收状态见本文末尾。

## 怎么使用

1. 打开 [Reader](https://poopsense-reader-0912.vercel.app/)；[poopsense.org](https://poopsense.org/) 保留为同一 Reader 的自有域名。
2. 在“我的 → 开发连接设置”连接自己的测试家庭，填写家庭 ID 与家庭查看密钥，API 地址留空。设备上传密钥和家庭查看密钥分别使用；均不是 DeepSeek 密钥。
3. 进入“健康 → 记录”，在“查找记录 ID”输入电脑上传回执里的 `session_id`，点击“查找”。
4. 手动采样详情中点击“生成 AI 演示解读”。只发一次生成请求，完成后显示本次实际模型与解读。
5. 刷新网页后，用同一个记录 ID 查找即可读取保存结果；不会自动重新调用模型。

硬件程序继续使用原 `POST /api/v1/device-sessions` 和原设备查询接口、地址与凭据。原 Reader 公网联调 ZIP 和 Exhibition 备用包保留，无需替换电脑上传程序。硬件端、浏览器均不持有模型密钥。

## 状态与失败处理

- **未生成**：点击生成才调用模型。
- **生成中**：可以离开；返回后读取状态。重复点击与多端同时提交复用同一任务。
- **完成**：显示已保存内容。再次提交相同记录/输入/提示版本仍复用结果。
- **失败**：不把固定规则说明当作模型成功；点击“重试生成”才重试。

网络中断、无法确认生成结果时，先点“重新读取状态”。过期的生成任务显示失败，仍需手动重试；页面刷新、读取及轮询均不触发新生成。

## 事实和模型的分工

模型只接收保存记录中允许的颜色、形状、原始模板相似度及其量纲、手动采样秒数和模拟/硬件测试标识；不发送家庭身份、成员资料、原始自由文本或凭据。只支持本次颜色/形状手动演示范围，超出范围明确返回不适用。

DeepSeek 实际返回的事实回显需与输入一致，正文每个分句必须属于当前事实允许的演示句式。模型可以组织顺序与选择表述；不允许添加健康判断、真实粪便分类、新传感器读数或把相似度改成准确率。未通过检查的回复保存为失败状态，不展示其正文，也不以规则拼接正文替代模型成功。

保存文字中的“系统演示边界”是系统固定补充，明确与模型正文区分。手动采样原来的 `processing.llm_status=not_applicable`、可靠性、原始观测、认领和规则结论均保留。此次解读不进入个人健康报告、趋势或基线。

## 服务端与持久化

- 家庭鉴权的 `GET/POST /api/v1/households/{household_id}/sessions/{session_id}/demo-explanation`；POST 参数为 `{"retry":false}`，显式失败重试为 `true`。
- 独立 `demo_explanations` 表保存输入事实及哈希、输入/提示版本、状态、实际模型、文字、次数、时间和失败历史。唯一约束与事务抢占防止跨实例重复调用，旧任务不能覆盖新尝试。
- 调用前后重新检查当前家庭与记录归属权限。设备密钥不能访问家庭解读；GET 仅查询。
- 模型请求有整体超时，不自动重试或切换供应商；等待模型期间不持有数据库事务。未配置 DeepSeek 或路由不是 DeepSeek 时如实失败。
