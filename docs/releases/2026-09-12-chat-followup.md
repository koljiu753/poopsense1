# 2026-09-12 · 键盘打开时也能看完回答

本轮修复手机问答中的两个已复现问题：键盘打开后，输入栏上移，但页面滚动范围没有补足，最后正文与评价即使滚到底也仍被挡住；用户正在回看旧内容时，新回复入口出现在消息列表末尾，落在当前屏幕之外。粉、黄、蓝、奶油白和黑色品牌保持不变。

## 变化

- 键盘覆盖页面时补足对应的尾部滚动空间，120px 多行草稿下仍可把最后正文与评价滚到输入栏上方。无键盘时的正常布局保留，收起键盘后导航与原有留白恢复。
- 新回复入口固定在手机输入栏上方，随键盘位置移动，同时预留按钮空间。点击只回到新回复，不提交或清空正在写的草稿。
- 用户通过 PageUp 回看旧内容时，迟到回复不会强行拉回最新位置；输入框内的方向键仍用于编辑，不被误判为改变阅读意图。
- 可见区域连续变化时保留草稿、选区和输入框内部滚动位置，相同定位值不重复写入。已有发送校验、中文输入法、Enter 换行与等待期间编辑行为保留。
- 后端源码加入 HTTP 连接复用及不记录敏感内容的耗时日志。没有切换默认模型；单次 Pro/Flash 对照受代理 TLS 和缓存等因素影响，不能据此证明模型速度差异。
