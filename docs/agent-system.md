# PoopSense Agent 体系

## 主 Agent

主 Agent 负责理解请求、确定任务目标、检查调用者身份、选择专业 Agent 和 Skill，并将任务运行写入可审计的 Agent Loop。主 Agent 不直接生成医疗结论，也不直接越过安全仲裁控制机器人。

## 专业 Agent

### 健康医生 Agent

- 解释结构化传感事实和个人趋势。
- 区分单次记录、连续变化和数据覆盖不足。
- 在确定性风险走廊内生成可理解的健康提示。

### 生活教练 Agent

- 把趋势转化为饮水、饮食、运动和作息建议。
- 结合用户自报目标和表达偏好组织行动步骤。
- 只能从安全规则提供的动作白名单中选择现实行动。

### 家庭管家 Agent

- 处理家庭成员、待认领记录和查看授权。
- 区分查看、编辑、通知和原始数据权限。
- 高影响操作进入等待确认状态，确认后才恢复执行。

### 主动关怀 Agent

- 根据趋势和规则发起适度提醒。
- 遵守成员开关、静默时段和每日频率限制。
- 红线安全流程与普通关怀频控相互独立。

### 社交/社区 Agent

- 社区内容必须由用户明确输入并同意发布。
- Agent 连接只共享别名和连接状态，不自动共享健康记录。
- 任意一方都可以撤回邀请或结束连接。

### 安全仲裁

安全仲裁采用确定性代码实现，检查：

- 输入数据是否可靠；
- 当前调用者是否拥有所需权限；
- 医疗表达是否越界；
- 机器人是否在线且满足动作前置条件；
- 是否已经取得用户明确确认；
- 超时、停止和失败时应进入哪一种终态。

## 记忆与 Soul

- 传感事实、自报信息、系统推断和反馈偏好分层保存。
- Soul 保存 Agent 名称、语气、主动偏好和长期关系目标。
- 每次 Soul 修改形成新版本，并保留修改人和时间。
- 表达偏好只能改变沟通方式，不能改变风险等级或原始事实。

## 可审计 Agent Loop

每次 Agent 任务包含：

1. 创建 run；
2. 主 Agent 路由；
3. 写入 handoff；
4. 专业 Agent 执行版本化 Skill；
5. 进行安全和授权复核；
6. 形成通知、软件结果或机器人动作；
7. 保存完成、失败、等待输入、取消等终态。
